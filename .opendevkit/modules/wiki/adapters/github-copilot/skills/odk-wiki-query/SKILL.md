---
name: odk-wiki-query
description: Answer questions using only the project's ODK Wiki
---

This command enters through the ODK orchestrator. Read `.opendevkit/modules/wiki/core/workflows/wiki-query.md` and delegate the query to one Wiki specialist. The Wiki specialist must search only `.opendevkit/wiki/` and return its answer or missing-information result to ODK. Do not consult project files, Git history, or external sources.
