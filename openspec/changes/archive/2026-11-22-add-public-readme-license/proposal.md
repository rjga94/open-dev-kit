# Proposal

## Why

The repository is becoming public but lacks the basic documentation and legal
notice that users need to understand ODK and reuse it with confidence.

## What Changes

- Add a root README that introduces ODK, explains the core install and optional
  module model, and links to the canonical installation and contribution guides.
- Add a root MIT license with Ricardo Abreu as the copyright holder.
- Keep the README focused on public users while preserving repository-maintainer
  guidance in CONTRIBUTING.md.

## Capabilities

### New Capabilities

None. This change adds repository documentation and a license only.

### Modified Capabilities

None. No existing runtime or behavioral requirements change.

## Impact

- Affected files: README.md and LICENSE.
- No source code, APIs, dependencies, install behavior, or OpenSpec behavior
  contracts change.
